# Lunara

One file. Buy once, own forever.

**Live:** https://justjude34-ship-it.github.io/lunara/

Open `index.html` in any browser. No install, no account, no server. Works offline after the first open.

## What is inside

- Two exclusive sound modes: binaural beats and singing bowls (never mixed)
- Binaural bands: Delta, Theta, Alpha, Beta, Gamma — headphones required
- Bowl sets: Deep, Earth, Tibetan, Crystal — soft spaced strikes with long decay
- Session lengths from 5 to 120 minutes
- Volume and fine controls for carrier, beat, and root pitch
- Private, offline, no accounts, no tracking

Headphones help the binaural beat lock in.

This is a calm relaxation tool, not medical treatment.
